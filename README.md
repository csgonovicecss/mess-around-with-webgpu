# MAWW. Mess Around With WebGPU

<a href="https://csgonovicecss.github.io/mess-around-with-webgpu/" target="_blank"><button>GitHub Page</button></a>

A browser-based physics sandbox made completely using HTML, JavaScript and WebGPU.

MAWW (Mess With WebGPU) is pretty much what the name says: a place to play with physics try out simulations create random objects and watch what happens.

Just do whateaver you want! Physics are cool, so is webgpu.

## Features

- **Soft Bodies** – Spawn jelly/deformable objects, pretty cool, but really performance heavy.

- **Cloth Simulation** – It looks nice! But as of now (26/11/15) the particle blending mechanism causes the cloth to look really bland.. Ill work on that.

- **Water Simulation** – As of now (26/11/15) it looks like jelly, im working on improving it and it looks pretty good now!

- **Volumetrics** – Make smoke, fire and big explosions. They look really nice, the smoke is incredible.

- **Object Spawning** – Spawn objects, for you know, messing around with webgpu..

- **WebGPU Rendering** – Uses the graphics features from the browser through WebGPU.

## Running Locally

MAWW needs a browser that supports WebGPU. (almost all chromium browsers support webgpu, if you use linux you might need to set additional flags if i remember correctly.)

1. Download this github repo as a zip.

2. Extract it.

3. And just run the html file! Make sure that the mp3 are next to the html file, the music is pretty cool, i like jazz.
